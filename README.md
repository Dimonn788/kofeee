# Кофе & Точка — сайт, касса, админка

Полноценный сервис на Node.js **без единой внешней зависимости** (никакого
`npm install`, никакого риска, что что-то не докачается на сервере
подрядчика). Хранилище — JSON-файл `data/db.json`; при росте бизнеса
переезд на PostgreSQL делается без изменения фронтенда, только внутри
`server.js`.

## Запуск

Нужен только установленный Node.js (14+, лучше 18+).

```
node server.js
```

Сервер поднимется на `http://localhost:3000` (порт можно поменять
переменной окружения `PORT`). Дальше:

- `/` — сайт для клиентов (меню + заказ навынос)
- `/cashier.html` — страница для кассира (планшет)
- `/admin.html` — панель владельца (меню, наличие, доход)

Для реального запуска положите папку на любой сервер с Node.js (VPS,
Render, Railway и т.п.) и настройте автозапуск `node server.js` через
pm2/systemd, чтобы сервер поднимался заново после перезагрузки.

## Доступы по умолчанию (обязательно смените перед реальным запуском)

| Роль    | Логин   | Пароль      | Что видит |
|---------|---------|-------------|-----------|
| Владелец | admin   | admin123    | Меню + доход (день/месяц) |
| Кассир   | cashier | cashier123  | Касса: приём заказов + флажки «закончилось» |

Пароль меняется правкой `data/db.json` — впишите новый пароль в поле
`password` у нужного пользователя и перезапустите сервер: он сам
пересчитает и сохранит хэш, а открытый пароль из файла удалит.

## Что уже умеет

**Сайт для клиентов**
- Меню тянется с сервера, товары «закончились» показываются как недоступные.
- Корзина, оформление заказа, отправка на сервер (не в никуда — заказ
  реально сохраняется и попадает в статистику владельца).

**Касса (для планшетов, оптимизировано под старые и слабые)**
- Без веб-шрифтов и тяжёлых эффектов — специально, чтобы не тормозило на
  Chrome 90 и медленном железе.
- Режим «Заказ» — кассир набирает заказ тапами по позициям.
- Режим «Наличие» — тот же экран, но тап переключает флажок «закончилось».
- Касса привязывается к одной из трёх кофеен один раз при входе на смену.

**Админ-панель владельца (ноутбук)**
- Добавление/редактирование/удаление позиций меню, смена цены и описания.
- Флажок «закончилось» — тот же, что видят кассиры и клиенты, в реальном
  времени.
- Выбор SVG-иконки для позиции вместо эмодзи.
- Доход за сегодня и за текущий месяц + графики за 14 дней и 12 месяцев.

## Важно перед реальным запуском на живой бизнес

Это рабочий прототип «под демонстрацию инвесторам и внутренний старт», а
не проект, прошедший аудит безопасности. Перед тем как принимать реальные
деньги и данные клиентов, стоит закрыть три вещи:

1. **HTTPS.** Сейчас сервер поднимается по обычному http — на реальном
   домене нужен TLS-сертификат (например, через Caddy/nginx перед
   Node-процессом), иначе логины и токены кассира/админа передаются в
   открытом виде.
2. **Сессии переживают перезапуск сервера.** Сейчас токены входа хранятся
   в памяти процесса — перезапуск сервера разлогинит кассу и админку
   (это не страшно, просто войти заново, но об этом стоит знать).
3. **Резервные копии `data/db.json`.** Это единственное хранилище заказов
   и меню — стоит настроить ежедневный бэкап файла на случай сбоя диска.
